# AI Language Teacher — Project Context

## 1. Project Overview

This project is a general-purpose AI language-learning web application.

The goal is to create an interactive AI teacher that allows users to:

- Have natural voice conversations in a target language
- Practice conversations at different difficulty levels
- Receive corrections on grammar and vocabulary
- Understand why something was incorrect
- Practice realistic scenarios
- Track recurring mistakes
- Track vocabulary and learning progress
- Receive personalized lessons and recommendations
- Gradually improve their speaking ability

The application should support multiple languages.

**Dutch is the first language being implemented because it is the most practical current use case.**

However, the architecture must remain language-agnostic. Dutch should never be deeply hard-coded into the application.

The long-term product is an **AI Language Teacher**, not specifically a Dutch teacher.
